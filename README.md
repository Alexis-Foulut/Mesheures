# Mes heures

Petite appli pour noter ses heures d'intérim, estimer son salaire net du mois et suivre son budget.

- Calendrier du mois : touche un jour pour noter tes horaires.
- Deux agences (Interaction et Acto), chacune avec son calcul : taux horaire, nuit, panier, fin de mission, congés payés, cotisations.
- Budget : dépenses prévues, revenus en plus, limites par catégorie.
- Import du relevé Caisse d'Épargne (fichier CSV exporté depuis le site).
- Sauvegarde : copier et coller ses données pour passer d'un téléphone à l'autre.

Les données restent sur le téléphone (stockage du navigateur). Rien n'est envoyé sur internet.

## Installer sur l'écran d'accueil

1. Ouvre l'appli dans Safari (iPhone) ou Chrome (Android).
2. iPhone : bouton Partager, puis « Sur l'écran d'accueil ». Android : menu ⋮, puis « Installer l'application ».
